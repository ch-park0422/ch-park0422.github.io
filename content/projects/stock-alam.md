## 문제

텔레그램에 /브리핑을 입력하면 에이전트들이 국내 시장을 분석해 리포트를 보냅니다.

## 설계 결정

- 시장, 섹터, 이슈, 돌파, 눌림을 맡은 에이전트 5개가 공통 하네스 위에서 동작합니다.
- 종목은 고정 목록 대신 실행할 때마다 네이버 금융에서 동적으로 수집합니다.

## 문제와 해결

{{< fix problem="Gemini 무료 티어에서 429 오류가 발생했습니다." >}}스로틀과 지수 백오프를 넣었습니다.{{< /fix >}}
{{< fix problem="네이버 수집이 간헐적으로 시간 초과됐습니다." >}}재시도를 넣고, 실패하면 yfinance로 전환합니다.{{< /fix >}}
{{< fix problem="GitHub Actions 크론의 지연이 컸습니다." >}}스케줄을 끄고 텔레그램, GAS, repository_dispatch로 이어지는 온디맨드 실행으로 바꿨습니다.{{< /fix >}}
{{< fix problem="텔레그램 웹훅이 같은 명령을 재전송해 발송이 반복됐습니다." >}}update_id 중복 제거와 쿨다운으로 막았습니다.{{< /fix >}}
