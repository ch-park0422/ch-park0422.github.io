- 원인 1: 첫 화면 등장 애니메이션이 투명도 0.35에서 시작해, 첫 표시와 최대 콘텐츠 표시가 애니메이션이 끝날 때까지 늦게 잡혔다. 애니메이션을 끈 빌드에서 Performance가 99로 오르는 것을 확인했다.
- 원인 2: 스크롤 등장 전 요소가 투명도 0.45여서, 스크롤하지 않고 검사하면 글자 대비가 1.5~4.3으로 측정됐다.
- 조치: 첫 화면 등장과 스크롤 등장 모두 위치만 움직이고 투명도는 바꾸지 않게 했다. 배경 흐림(`backdrop-filter`)은 점수에 영향이 없어 그대로 두었다.

남은 개선 여지: 프로필 사진(102 KiB)을 화면 크기에 맞게 줄이면 약 58~83 KiB를 아낄 수 있다고 측정됐다.

## Playwright

`cd tests && npm test`. Playwright 1.64.1, axe-core 4.14.0, Chrome.
데스크톱(1280×900), 태블릿(768×1024), 모바일(360×780)에서 각각 11개, 모두 33개 통과.

- 홈: 제목과 부제, 섹션 순서(첫 화면, 경력과 학력, QA 역량, 사이드 프로젝트, 소개, 연락), 요약 4칸, 경력 4곳, 대표 프로젝트 4개, 학력과 자격 4개, QA 역량 4개, 사이드 프로젝트 카드 3개와 목록 5개, 넓힌 역량 6개
- AI가 놓친 문제 4개와 프롬프트 3개만 먼저 보이고, 펼치면 9개씩 보임
- 사이드 프로젝트 카드에서 실제 상세 주소로 이동
- 움직임 줄이기 설정에서는 등장 효과가 붙지 않음
- 홈, 소개, 이력서에 이전 문구(`풀스택 개발자`, `AI로 구현하고`, `2017~`), 학점, 이메일 주소가 없음
- 프로젝트 상세, 기술 필터, 글 상세와 목록, 404, 본문 건너뛰기 링크
