첫 측정에서 홈은 Performance 63(LCP 6.1 s), 프로젝트 상세는 68(LCP 5.1 s)이었다.
원인은 Google Fonts CSS가 렌더링을 막는 것이었다(LCP의 91~93%가 렌더 지연).
웹폰트 CSS를 비동기로 붙이고 사이트 CSS를 인라인으로 넣어 위 결과가 됐다.
대신 폰트가 바뀌면서 홈의 CLS가 0.084로 생겼다. 좋음 기준(0.1 미만) 안이다.

## Playwright

`cd tests && npm test`. Playwright 1.64.1, axe-core 4.14.0, Chrome.
데스크톱(1280×900)과 모바일(360×780)에서 각각 8개, 모두 16개 통과.

- 홈: 섹션 순서, 수치, 역량 6개, 사례 9개, 프롬프트 9개, 프로젝트 타일과 목록
- 홈 타일 클릭 시 프로젝트 상세 주소로 이동
- 프로젝트 상세: 사례 연구 7개 절 순서, 수치, 다음 프로젝트 링크
- 프로젝트 목록: 기술 필터와 주소 갱신
- 글 상세: 읽는 시간, 태그, BlogPosting 구조화 데이터, 공유 이미지
- 글 목록에서 상세로 이동
- 404: 주요 페이지 안내
- 키보드 첫 Tab이 본문 건너뛰기 링크에 닿음

접근성 검사(axe)는 홈, 프로젝트 상세, 프로젝트 목록, 글 상세, 404에서 실행했고 serious·critical 위반은 0건이다.
